📖 API 速查
constructor(container, options?)
创建 SpinePlugin 实例，创建 WebGL canvas 并挂载到容器中
container string|HTMLElement — CSS 选择器（如 "#myId"）或 DOM 元素
options.format 'json' | 'binary' — spine 数据格式，默认 'json'
options.backgroundColor string — canvas 背景色，默认 'rgba(0,0,0,0)'
options.autoResize boolean — 自动监听容器大小变化，默认 true
await plugin.init()
初始化渲染环境（WebGL 上下文、SceneRenderer、AssetManager），必须在 addSpine 之前调用
返回 Promise
await plugin.addSpine(id, config)
加载 spine 资源并添加到场景中。id 必须唯一，重复添加会抛出异常
id string — 唯一标识，后续所有操作都通过此 id 引用
config.jsonUrl string — .json 文件 URL（必填）
config.atlasUrl string — .atlas 文件 URL（必填）
config.x number|string — x 偏移，支持百分比如 '50%'，默认 0
config.y number|string — y 偏移，支持百分比如 '50%'，默认 0
config.scale number — 缩放比例，默认 1
config.loop boolean — 是否循环播放，默认 true
config.animationName string — 初始播放的动画名，默认 null（不自动播放）
config.speed number — 播放速度倍率，默认 1
config.playFrom number — 播放起始百分比 0-100，默认 0
config.playTo number — 播放结束百分比 0-100，默认 100
config.autoFit boolean — 自动适配 canvas 大小，默认 true
config.premultipliedAlpha boolean — 预乘 Alpha，默认 true
config.virtualViewport object|null — 虚拟视口 { width, height }，默认 null
plugin.playAnimation(id, animationName, loop?)
立即播放指定动画，替换当前轨道的动画。如果当前有动画正在播放，会被中断并触发 interrupt 事件
id string — spine 标识
animationName string — 动画名称
loop boolean — 是否循环，不传则使用 addSpine 时的 loop 配置
plugin.addAnimation(id, animationName, loop?, delay?)
将动画加入播放队列，当前动画播放完后自动切换到队列中的下一个动画（依次播放）。
loop 行为说明：
  • 如果 loop=false（默认），该动画播放一次后自动切换到队列中下一个动画
  • 如果 loop=true，该动画会一直循环，队列中后续的动画将不会被播放
  • 如果需要无限循环播放队列，需监听 complete 事件，在回调中重新 addAnimation
id string — spine 标识
animationName string — 动画名称
loop boolean — 是否循环，默认 false
delay number — 延迟秒数（相对当前动画结束时间），默认 0
plugin.setPosition(id, x, y)
设置 spine 在 canvas 中的位置偏移
x number|string — 支持数值或百分比如 '50%'
y number|string — 支持数值或百分比如 '50%'
plugin.setScale(id, scale)
设置 spine 的缩放比例
scale number — 缩放倍率，如 0.5 表示缩小一半
plugin.setSpeed(id, speed)
设置 spine 动画播放速度
speed number — 速度倍率，如 2 表示两倍速
plugin.setPlayRange(id, from, to)
设置动画播放范围（百分比），实现片段循环
from number — 起始百分比 0-100
to number — 结束百分比 0-100，必须大于 from
plugin.removeSpine(id)
移除指定 spine 并释放其 GPU 资源。id 不存在时会抛出异常
id string — 要移除的 spine 标识
plugin.on(id, event, callback)
注册 spine 事件监听器
id string — spine 标识
event 'start' | 'interrupt' | 'end' | 'dispose' | 'complete' | 'event' — 事件类型
callback function(data) — 回调函数，接收事件数据对象
plugin.off(id, event, callback)
移除指定的事件监听器（必须传入与 on 相同的回调引用）
id string — spine 标识
event string — 事件类型
callback function — 要移除的回调函数
plugin.destroy()
销毁所有 spine 实例、释放 GPU 资源、移除 canvas。调用后不能再执行任何操作
无参数
